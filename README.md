# Lava-Rápido Espuma

Checkpoint de **Roteamento de Páginas e Uso de Contexto**, feito com React, Vite, TypeScript, Tailwind CSS, react-router e `useContext`.

## Como rodar

```bash
npm install
npm run dev
```

## Páginas

- `/` Home: apresentação, serviços e depoimentos com fotos
- `/agendamentos` Formulário de tíquetes (nome, modelo, placa, tipo de lavagem) com exclusão
- `/sobre` Integrantes do grupo com RM e foto

O cabeçalho mostra, via contexto, quantos carros aguardam lavagem.
